개인정보처리방침

시행일: 2026년 9월 20일 · 운영: 두드리

두드리는 학교 이메일을 확인하고 프로필, 프로젝트, 커피챗 및 AI 문서를 관리하는 서비스입니다. 이 안내는 두드리 앱에서 처리하는 정보와 이용자가 선택할 수 있는 사항을 설명합니다.

1. 처리하는 정보와 이용 목적

  • Google 로그인: Google과 Supabase가 확인한 연계 사용자 식별자, 이메일 및 표시 이름을 계정 생성, 로그인과 저장 자료의 소유자 확인에 사용합니다. Google 비밀번호는 두드리가 수집하지 않습니다.
  • 학교·회사 이메일 확인: 입력한 이메일, 학교·학과·학적 상태 또는 회사명과 확인 시각을 저장합니다. 해당 이메일 접근 여부를 확인하는 기능이며 재학·졸업·직무·직급의 사실 확인을 의미하지 않습니다. Google 로그인 이메일과 학교 이메일은 달라도 됩니다.
  • 프로필과 활동: 직접 입력한 프로필·경력·관심사·활동 조건, 프로젝트·지원·커피챗·일정 및 알림을 해당 기능 제공에 사용합니다.
  • 자료와 AI 문서: 사용자가 올린 자료, 승인한 정보, 생성 요청, 생성 문서와 저장 버전을 자료 관리 및 요청한 생성·편집·공개 기능에 사용합니다.
  • 인증과 운영: 인증 토큰의 해시, 세션 만료·철회 기록을 인증과 재사용 방지에 사용합니다. 서비스 제공 과정에서 호스팅 업체가 IP 주소, 요청 및 오류 등의 운영 기록을 처리할 수 있습니다.

2. 공개 범위와 AI 전송

프로필의 공개 범위와 문서 게시 여부는 이용자가 선택합니다. 공개한 정보와 게시 문서는 다른 사람이 열람할 수 있습니다. 게시를 철회해도 이미 열람한 사람이 따로 저장한 사본까지 회수할 수는 없습니다.

AI 기능을 요청하면 해당 기능에 필요한 프롬프트와 선택·승인한 정보를 연결된 AI 서비스로 전송합니다. 비공개·미승인 자료는 공개 문서 생성 입력에서 제외합니다. 자료 분석이나 개인 디자인 예시 생성 등 별도 전송이 필요한 기능은 화면의 전송 동의를 거칩니다.

3. 이용하는 외부 서비스

  • Supabase: Google 인증 연계 및 계정·프로필·저장 문서 등 앱 DB 보관. 현재 앱 DB는 서울 리전입니다.
  • Vercel: 앱 화면 제공과 API 요청 전달.
  • Render: API, 작업 실행 및 공개 문서 제공. 현재 API 서버는 싱가포르 리전입니다.
  • Brevo: 입력한 수신 이메일로 인증 링크 발송.
  • 국민대 AI API: 이용자가 요청한 AI 처리에 필요한 프롬프트와 정보를 전달합니다. 연결 서비스 및 모델 제공자의 처리 조건이 적용됩니다.

외부 서비스는 서비스 제공에 필요한 정보를 국내외에서 처리할 수 있습니다. 제공자별 운영 기록·백업의 보관 및 삭제에는 해당 제공자의 처리 조건이 적용됩니다. 관련 문의는 아래 운영 연락처로 보내 주세요.

4. 보관 및 삭제

계정, 프로필 및 저장 자료는 이용자가 삭제를 요청하기 전까지 보관합니다. 별도의 자동 삭제 기한은 적용하지 않습니다. 삭제 요청은 운영 이메일로 접수하며, 계정 소유자를 확인한 뒤 운영자가 처리하고 필요한 사항을 안내합니다.

프로필 수정, 자료 철회 및 문서 게시 중지는 앱에서 할 수 있습니다. 게시 중지는 저장 원본의 삭제와 다릅니다. 계정과 저장 자료의 삭제를 원하면 이메일로 요청해 주세요. 외부 제공자의 백업·운영 기록은 즉시 삭제되지 않을 수 있습니다.

인증 링크는 15분 동안 한 번 사용할 수 있으며 앱 로그인 세션은 최대 30일입니다. 인증 자격의 만료는 관련 기록의 자동 삭제를 의미하지 않습니다.

5. 브라우저 저장과 이용자 선택

로그인 access token은 브라우저 메모리에, refresh token은 자바스크립트로 읽을 수 없는 HttpOnly 쿠키에 보관합니다. 앱 DB에는 세션 토큰의 해시를 저장합니다. 쿠키를 차단하면 로그인 유지 기능이 동작하지 않을 수 있습니다.

같은 탭에서 입력 중인 일부 초안과 화면 복원 정보는 sessionStorage에 보관합니다. 탭 종료 시 브라우저 정책에 따라 삭제되며 정식 저장된 자료는 서버에 남습니다. 로그아웃하면 해당 앱 로그인 세션을 철회합니다.

선택 정보를 입력하지 않거나 AI 전송에 동의하지 않을 수 있습니다. 이 경우 해당 정보를 필요로 하는 기능은 제한될 수 있습니다. Google 계정 연결 권한은 Google 계정 설정에서도 관리할 수 있습니다.
