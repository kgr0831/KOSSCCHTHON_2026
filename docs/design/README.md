## 최신 시안 적용

모바일 홈 `43:12`, 탐색 `43:132`, 등록 `43:237`, 커피챗 `43:315`, 마이 `43:407`을 공통 UI 기준으로 삼았습니다. 후속 요청에서 최신 Page 1 메타데이터와 홈, 커리어맵 `43:853`, 모집 작성 `43:545` 디자인 컨텍스트를 다시 확인했습니다.

- 모바일의 보라색·청록색 그라데이션, 밝은 배경, 둥근 카드, pill 버튼·탭을 PC에도 공유합니다.
- 모바일은 하단 5개 메뉴, PC는 사이드바와 등록 버튼입니다. 등록창에서 모집 작성·경험·커피챗·AI 스튜디오로 이동합니다.
- 앱 내부 이동은 주소와 고정 메뉴를 유지하며 본문만 전환합니다. ‘나의 공간’ 선택과 현재 화면 이름을 표시하고, 낮은 PC 화면은 스크롤 대신 메뉴 배치를 줄입니다. 로그인·입력 오류·저장 확인은 앱 대화상자입니다.
- 로고·캐릭터는 Figma에서 받은 원본 이미지입니다. 캐릭터 시트는 CSS로 잘라 사용합니다.
- 프로필 완성도는 실제 5개 입력 항목, 약속·알림·경력은 실제 DB 조회 결과입니다.
- 추천은 사용자가 요청한 임의 순서로 제공하며 점수나 AI 적합도를 표시하지 않습니다.
- 새 스튜디오·자료 검토·AI 설정·모집 작성·커리어맵에도 같은 모바일 디자인을 사용합니다.

## Design 폴더와 레퍼런스 이미지

`Design/*.md`의 style_id·설명·전체 가이드를 읽어 선택지와 AI 입력으로 사용합니다. 같은 가상 인물의 내용을 각 가이드에 맞게 HTML/CSS로 구성한 뒤 Edge에서 PNG로 렌더링했습니다. AI 결과물은 이 예시와 같은 스타일을 따르며 요청에 따라 달라집니다.

스튜디오에서 기본 예시를 비교·확대하고 디자인을 선택합니다. 추가된 `editorial-portfolio.md`의 Studio Journal과 사용자가 업로드한 MD는 같은 가상 인물로 Claude가 HTML/CSS를 생성하고, 격리된 Edge에서 PC·모바일 PNG로 렌더링합니다. 원문과 이미지·작업 상태는 개인 DB에 저장합니다. 임의의 새 MD를 기존 테마 이미지로 대체하지 않습니다.

GUI는 표시한 문구·목록·섹션 순서·색·폰트·간격을 편집하고, 코드 편집에서는 HTML/CSS/JS를 직접 저장합니다. 자유 코드의 CSS와 섹션의 원래 부모·중첩 프로젝트 그리드를 보존합니다. 포트폴리오는 작업과 기여를 보여주는 웹사이트, CV는 학력·경력·기술 중심의 인쇄 문서로 구분합니다.

## 검증

2026-09-19 Windows Edge headless 기준입니다.

- 프런트 프로덕션 빌드, TypeScript 검사 통과.
- Playwright 18개 통과: 320–1440px 반응형, 320px 높이의 PC 메뉴, 내부 주소·이력·새로고침, 로그인 모달, GUI 저장 확인, 디자인 MD 업로드, 캘린더, 스타일 선택·편집, generated iframe 외부 이동 차단.
- 실제 더미 계정 로그인 후 스튜디오·커리어맵·자료·프로젝트·모집 작성·AI 설정의 390/1440px 화면에서 API 오류와 가로 넘침 없음.
- 국민대 Haiku 초안, 종류를 분리한 Sonnet 포트폴리오·CV, 새 디자인의 PC·모바일 예시 PNG 생성·DB 저장·실제 화면 표시 확인.
- GUI 검증에서 발견한 헤더 제거·섹션 이동 문제를 수정하고 회귀 테스트 추가. 이전 실패 초안은 보존하고 새 생성 버전을 검증했습니다.
- 테스트 fixture는 자동화 테스트에만 존재합니다. 로컬 체험용 더미 데이터와 실제 AI 예시 생성본은 별도로 DB에 저장했습니다.
- CLI 실제 생성은 로그인 필요 상태입니다. 실제 휴대전화 기기 검증은 수행하지 않았습니다.

실행·환경 설정은 [루트 README](../../README.md)를 참고하세요. `start-local.bat` 한 개로 전체를 실행합니다.
