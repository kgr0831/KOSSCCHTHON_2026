## 이용하는 외부 서비스

- Supabase: Google 인증 연계 및 계정·프로필·문서 등 앱 DB 저장. 현재 앱 DB는 서울 리전입니다.
- Vercel: 앱 화면과 API 요청 전달.
- Render: 앱 API·작업 실행·공개 문서 제공. 현재 API 서버는 싱가포르 리전입니다.
- Brevo: 사용자가 입력한 수신 이메일로 인증 링크 발송.
- 국민대 AI API: 사용자가 AI 기능을 요청하면 해당 기능에 필요한 프롬프트와 선택·승인한 정보를 전송합니다. 연결 서비스 및 모델 제공자의 처리 조건도 적용됩니다.

외부 서비스는 운영에 필요한 데이터를 국내외에서 처리할 수 있습니다. 현재 확인하지 않은 제공자별 원본 로그 보관 기간을 임의로 확정하지 않았습니다.

## 공개와 브라우저 저장

프로필의 공개 범위 설정과 문서 게시 여부는 사용자가 선택합니다. 공개한 정보와 게시한 문서는 다른 사람이 열람할 수 있습니다. 게시를 철회해도 이미 열람한 사람이 별도로 저장한 사본까지 회수하지는 못합니다.

로그인 access token은 브라우저 메모리, refresh token은 HttpOnly 쿠키에 보관합니다. 앱 DB에는 세션 토큰의 해시를 저장합니다. 같은 탭에서 입력 중인 일부 초안과 화면 복원 정보는 sessionStorage에 저장하며 탭 종료 시 브라우저 정책에 따라 삭제됩니다.

## 보관·삭제 — 운영자 결정 필요

현재 계정·프로필·저장 자료에 자동 삭제 기한은 구현되어 있지 않습니다. **제안하는 기준은 계정 사용 및 자료 보관을 요청하는 동안 유지하고, 이용자가 운영 문의 이메일로 삭제를 요청하면 운영자가 처리하는 방식입니다.** 처리 기한과 외부 제공자의 백업·로그 보관 예외는 운영자가 확정해야 합니다.

인증 링크는 15분 동안 한 번 사용할 수 있고 앱 세션은 최대 30일입니다. 인증 자격의 만료는 관련 DB 기록의 자동 삭제와 같은 의미가 아닙니다.
