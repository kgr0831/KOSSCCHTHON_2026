# Studio Journal

웹 포트폴리오와 개인 소개를 위한 편집 디자인입니다.

- 배경은 종이색 #F7F4EE, 본문은 남색 #182A3A, 강조는 코랄 #D86142.
- 넓은 여백, 얇은 남색 구분선, 큰 타이포그래피와 작은 대문자 인덱스를 사용합니다.
- 처음에는 한 문장 소개를 크게 보여주고 아래에 대표 작업을 두 열의 카드로 배치합니다.
- 각 작업은 프로젝트명, 문제, 실제 역할, 해결 과정, 결과와 배운 점을 담습니다.
- 상세 설명은 펼쳐서 읽을 수 있게 합니다. 실제 작업이 없으면 없는 경험을 만들지 않습니다.
- 모바일에서는 한 열로 배치하고 제목 크기와 패딩을 줄여 가로 스크롤을 없앱니다.
- CV로 선택한 경우에는 같은 색과 서체를 쓰되, 학력·경험·기술을 정리한 간결한 인쇄 문서로 구성합니다.
- 모션은 짧은 페이드와 자연스러운 이동을 사용하며 reduced-motion을 지원합니다.
