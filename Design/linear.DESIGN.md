# 스타일 가이드: 미니멀 · 프로 (Linear 스타일)

## 무드
근접 블랙 캔버스(#010102) 위에 옅은 회색 텍스트, 라벤더 블루(#5e6ad2) 단 하나의 포인트 컬러만 사용.
장식 없이 정밀하고 기술적인 인상. 카드는 얇은 테두리를 가진 차콜 패널로 표현.
